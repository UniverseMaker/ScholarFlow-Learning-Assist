AI 연결

AI 서버에 연결되어 있지 않아요. 아래에서 LLM 프로필을 불러와 연결하면 AI 기능을 쓸 수 있어요.

🔒 연결 정보는 계정마다 따로 저장돼요 — 같은 브라우저의 다른 계정은 볼 수 없어요. 다만 API 키는 이 브라우저에 평문으로 있으니 공용 PC에서는 사용 후 연결을 끊고 프로필을 지우세요.

☁ 내 계정 보관함 — 올리기 · 받아 쓰기

연결 정보를 계정 이름 + 암호 문구로 잠가 올려 두면, 다른 브라우저(같은 서버 주소로 연 경우)에서 같은 이름의 계정으로 로그인한 뒤 [받아 쓰기] 한 번으로 바로 연결돼요. DB 없이 이 PC 의 폴더(userdata/llm-vault)에 암호문만 저장해요 — 서버·관리자·다른 계정은 내용을 볼 수 없고, 암호 문구를 잊으면 복구할 수 없어요.

메뉴 관리

순서를 바꾸거나(▲▼) 개별 메뉴를 꺼요. 끈 메뉴는 내비에서 사라지고, 주소로 직접 들어가도 홈으로 보내요. 홈·관리자·시스템 설정은 항상 켜져 있어요.
메뉴는 그룹(자료·설정·관리자)별로 묶여 표시되고, ▲▼ 순서는 같은 그룹 안에서 적용돼요. 다른 자리로 옮기고 싶으면 그룹을 바꾸세요(‘(맨 위)’는 제목 없이 맨 위, ‘(기타)’는 제목 없이 아래쪽).
