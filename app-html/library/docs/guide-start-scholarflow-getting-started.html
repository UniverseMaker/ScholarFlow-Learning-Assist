입문약 10분#시작하기

1. 서버 켜기

ScholarFlow 는 파이썬 표준 라이브러리로 만든 서버 하나로 돌아갑니다. 데이터는 데이터 폴더에 모입니다.

python -m pip install -r requirements.txt
python serve.py 18162 --data-dir="D:/scholarflow-data"

브라우저에서 http://127.0.0.1:18162 를 엽니다.

데이터 폴더 = 전부 — 계정·프로젝트·문서·로그·백업이 모두 이 폴더에 있습니다. 폴더를 통째로 복사하면 다른 PC 로 옮겨집니다.

2. 관리자 비밀번호

처음에는 admin 계정에 비밀번호가 없어 로그인할 수 없습니다. 비밀번호는 서버 PC 에서만 정합니다.

python tools/local_admin.py set --data "D:/scholarflow-data"

또는 서버 PC 브라우저로 http://127.0.0.1:18162/local-admin 을 엽니다. 12자 이상으로 정하세요.

3. AI 연결

[설정 → AI 연결]에서 OpenAI 호환 주소·모델·키를 등록하고 연결을 누릅니다. 키는 서버에 암호화되어 저장되고 브라우저로 내려오지 않습니다.

4. 첫 연구 프로젝트

  1. 🔬 연구지원 모드 → 연구 프로젝트 → 새 프로젝트
  2. PDF·Word·한글 문서를 올립니다. 쪽 단위로 색인됩니다.
  3. 대화창에 질문하면 AI 가 (파일 p.쪽) 형태로 근거를 인용해 답합니다.
  4. 좋은 답은 작업 문서로 보내고, DOCX·PPTX·HTML·MD 로 내보냅니다.

5. 학습 자료 읽기

📚 자료 학습 모드의 학습 자료에서 문서를 고르면 뷰어가 열립니다. 아래 리딩 메이트 막대로 요약·읽어 주기·형광펜을 쓰고, 💬 물어보기(Alt+A)로 지금 보이는 대목에 대해 묻습니다.

자료 추가 — 새 문서는 app-html/library/docs/ 에 넣고 python tools/build_catalog.py 를 실행합니다. 자세한 규격은 도움말 '학습 자료 만들기 · 등록'.

6. 스스로 확인

  1. 다른 PC 로 옮길 때 무엇을 복사하나요?
    답 보기데이터 폴더 전체. 새 PC 에서 --data-dir 로 가리킵니다.
  2. 관리자 비밀번호는 어디서 정하나요?
    답 보기서버 PC 에서만 — tools/local_admin.py 또는 /local-admin 화면.
