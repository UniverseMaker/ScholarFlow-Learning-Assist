# 관리자

## 비상용 관리자(admin)
- 서버를 처음 켜면 `admin` 계정은 **비밀번호 미설정**이라 로그인할 수 없어요.
- 비밀번호는 **서버 PC 에서만** 정합니다(원격·공개 주소에서는 막혀 있어요).
  - 명령: `python tools/local_admin.py set --data <데이터 폴더>` (스크립트에서 쓸 땐 `--password-stdin`)
  - 화면: 서버 PC 브라우저에서 `http://127.0.0.1:<포트>/local-admin`
- 12자 이상. 실패가 잦으면 잠깁니다. 상태 보기: `python tools/local_admin.py status`

## 계정 · 서버 관리
계정 만들기·잠그기·역할·**기능 권한**(연구지원 / 자료 학습) · 보안 정책 · 서버 상태 · 로그 보기 · 통합로그인(선택) 설정.

## 연구지원 관리
저장소 폴더 · 로컬 폴더 연결 · 전체 프로젝트 · 백업 복원 · 연구행정 연결 · AI 게이트웨이(다른 시스템이 쓰는 토큰).
