# 학습 자료 읽기

**학습 자료**는 한 편 한 편이 완결된 HTML 학습 문서입니다(자기 스타일·스크립트를 품고 있어 앱 안 틀(iframe)에 띄워요).

## 목록
- **왼쪽 필터**: 분류 · 갈래(분류를 고르면 좁혀짐) · 수준 · 태그(검색·더 보기) · 상태 · 읽기(안 읽음/읽는 중/다 읽음) · 출처(기본 제공/앱 등록) · ★ 즐겨찾기만. 숫자는 지금 조건에서의 편수.
  - 같은 칸 안은 "하나라도"(OR), **태그만 "모두 포함"(AND)**. ⚲ 필터 버튼으로 패널을 접을 수 있어요.
- 위쪽: 검색( **/** 키로 바로) · 정렬(추천=분류순 · 최신 · 제목 · 짧은/긴 것 · 최근 읽음) · 보기(목록·카드·트리) · 활성 필터 칩(✕로 하나씩 해제)
- 필터가 없을 때 **📖 이어 읽기**(읽던 자료 · 진행 막대) · **★ 즐겨찾기** 선반
- 줄마다 ☆(즐겨찾기) · 수준 · 분량 · 갱신일 · 상태 · #태그(누르면 그 태그로 거르기) · 읽은 위치 막대
- **⬆ 자료 등록**(관리자) → [학습 자료 만들기·등록](#help:authoring)

## 뷰어 — 왼쪽 자료 목록 · 가운데 본문 · 오른쪽 목차
- **가운데는 본문만**: 기본 보기(**앱에 맞춰 보기**)에서는 문서 안의 목차·이동 경로·바닥글·작성용 '검토 필요' 표시를 숨기고, 색을 지금 앱 테마(라이트/다크)에 맞춥니다. 일부 문서 그림에서 색이 빠져 검게 보이던 곳도 문서 자신의 색으로 채워 줘요.
- **오른쪽 목차**: 문서의 제목들로 만든 목차. 누르면 그 대목으로 가고, 읽는 위치에 따라 지금 항목이 표시돼요. 막대의 **목차** 버튼으로 보이기/숨기기.
- **왼쪽 자료 목록**: **[관련 문서]** = 목록 화면에서 건 필터 결과(필터가 없으면 지금 문서와 같은 갈래) · **[전체 문서]** = 모든 자료를 분류별 묶음으로(지금 문서 묶음은 펼친 채). 검색은 지금 범위 안에서 하고, 관련 문서에 없으면 **"전체 문서에서 n편 더 보기 →"** 로 넘어가요.
- 자리: **와이드 모드** = 목록 | 본문 | 목차 3단 · **일반 모드** = 본문은 일반 폭을 그대로, 목록·목차는 바깥 왼쪽/오른쪽 여백 · 창이 좁으면 **☰**(목록)·**목차** 버튼으로 여는 서랍
- **‹ ›** 이전·다음 자료( **[ ]** 키) · **A− A+** 글자 크기 · **▤ 읽기 배치** · **☆** 즐겨찾기 · **⎙** 인쇄/PDF · 새 탭
- **읽은 위치**가 저장되고, 다시 열면 거기서부터. 90% 이상 읽으면 "다 읽음".

## ▤ 보기 방식 · 본문 폭
- **보기 방식**: 앱에 맞춰 보기(권장) / **문서 원본 그대로**(문서가 만든 색·배치·목차 — 원본에선 문서 안 목차 위치·머리 고정도 고를 수 있어요)
- **본문 폭**: 좁게 · 기본 · 넓게 · 최대 — 브라우저의 `lds:layout` 에 저장돼 새 탭에서 연 문서에도 적용
- **오른쪽 목차** 보이기/숨기기

## 알아 두기
- 학습 자료를 연 기록은 **감사 기록**(열람 · 머문 시간)에 남습니다.
- 자료를 보며 💬 물어보기를 누르면 **지금 화면에 보이는 대목**을 근거로 답합니다.
- 문서를 직접 만들 때 그림 색은 문서의 `--fg`·`--bg`·`--border` 같은 변수를 쓰세요(정의 안 된 변수는 검게 나와요) → [자료 만들기](#help:authoring)
