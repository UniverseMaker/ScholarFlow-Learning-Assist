# 설정

[설정] 화면과 계정 메뉴에서 바꿉니다. 표시 설정은 계정마다 저장돼요.

| 묶음 | 내용 |
|---|---|
| 표시 | 테마(팔레트) · 밝게/어둡게 · 왼쪽/위쪽 메뉴 · 글꼴 · 글자 크기 · 내용 폭 · 탑메뉴 폭 |
| AI 물어보기 | 넓은 화면에서 오른쪽에 펼쳐 두기 / 떠 있는 버튼 |
| AI 연결 | 연결 등록·고르기·테스트·내보내기 → [AI 연결](#help:ai) |
| 고급(LLM) | 지금 연결된 모델 이름 · temperature |

## 모드별 설정
- **연구지원 설정** — 대화 근거 분량(찾을 조각 수 · 최대 글자) 등
- **자료 학습 설정** — 도구함 기본 범위 · 읽기 설정 자동 적용 · 리딩 메이트 막대 숨기기

## 시스템 설정(관리자)
앱 이름·로고·파비콘·부제 · 메뉴 순서·켜고 끄기 · 새 사용자 기본 표시 · 감사 기록 수집 스위치.
