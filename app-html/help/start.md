# 처음 오셨나요 — 메뉴 지도

ScholarFlow 는 **연구 자료를 정리해 문서로 만들고**, **학습 자료를 읽으며 AI 와 공부하는** 웹앱이에요.
서버(`serve.py`) 하나로 돌아가고, 데이터는 서버의 데이터 폴더에 파일(또는 SQLite 한 파일)로 저장됩니다.

## 두 가지 모드
화면 위쪽(또는 왼쪽 위)의 모드 버튼으로 오가요. 설정·관리자·AI 연결은 두 모드 공통이에요.

| 모드 | 하는 일 |
|---|---|
| 🔬 **연구지원** | 프로젝트에 PDF·문서를 올려 AI 와 읽고, 근거를 인용해 보고서·논문·발표자료로 만들기 |
| 📚 **자료 학습** | 학습 자료(HTML 문서)를 읽으며 요약·질문·복습 카드·노트·서술형 연습 |

## 🔬 연구지원 메뉴
- **오늘 연구** — 지금 할 일, 멈춘 프로젝트와 이유, 정리 안 된 자료, 최근 활동
- **연구 프로젝트** — 자료 올리기 · 쪽 단위 근거 인용 대화 · 작업 문서 · DOCX/PPTX/HTML/MD 내보내기 → [연구지원](#help:research)
- **AI 작업** — 자료 정리 · 문헌 검토 · 심사 반복 · 제출 전 점검을 서버에서 끝까지(결과 저장은 확인 카드로)
- **프로젝트 정보·관리** — 과제 기본 정보 · 기간 · 예산 · 목표 · 참여기관
- **논문 작성·보조** — 브라우저 안 LaTeX 작업실(서버 PC 에 TeX 엔진이 있으면 PDF 컴파일)
- **보고서 작성·보조** — 쪽 나눔이 되는 문서 편집기 · Word/PDF 내보내기
- **발표자료 작성·보조** — 슬라이드 작업실 · PPTX/PDF 내보내기
- **문헌·선행연구 · 심사·평가 대비 · 심층 조사·지식맵 · 회의·설문·메모** — 주제별 도구 모음
- **작업 이력 · 저장소** — 모든 프로젝트의 타임라인과 저장소 상태

## 📚 자료 학습 메뉴
- **학습 자료** — 목록(표·카드·트리) · 필터 · 뷰어(목차·읽은 위치·리딩 메이트 막대) → [학습 자료 읽기](#help:library)
- **내 학습 폴더** — 자료를 주제별 폴더로 묶기
- **복습 카드 · 노트 허브 · 서술형 연습 · 대화·말하기 · 개념 지도 · 학습 계획** — 고른 자료를 근거로 공부하는 화면

## 어디서나
- **💬 물어보기**(Alt+A) — 지금 보고 있는 화면·자료를 맥락으로 AI 에게 묻기
- **Ctrl+K** — 메뉴·명령·프로젝트·문서 찾기
- 계정 메뉴(오른쪽 위 이름) — 계정·보안, 설정, 도움말, 로그아웃
