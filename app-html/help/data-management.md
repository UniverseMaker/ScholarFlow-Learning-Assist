# 🗂 자료·데이터 관리 가이드

ScholarFlow의 모든 데이터가 **어디에, 어떤 폴더 구조로** 저장되는지 정리했어요. 백업·복원·이사·정리하는 방법과 관리 점검표도 함께 있어요.

이 앱은 **백엔드(서버) 전용**이에요. 데이터의 기준은 서버 PC 의 **데이터 폴더**이고, 브라우저는 임시 보관(캐시)만 해요.

## 1. 한눈에 보기

| 무엇 | 어디에 | 누가 바꾸나 |
|---|---|---|
| 앱 프로그램(화면·학습 자료 원본) | 프로그램 폴더 `app-html/` | 개발·관리자 |
| 계정·보안 정책·암호화 키 | `<데이터 폴더>/system/` | 서버(관리자 화면) |
| 내 설정·화면 상태 | `<데이터 폴더>/users/<계정 id>/study/` | 앱이 바뀌는 순간 저장 |
| 내 학습 자료 데이터(문서별) | `users/<id>/library/<문서 id>/` | 앱이 바뀌는 순간 저장 |
| 연구 프로젝트(자료·문서·대화·내보내기) | `users/<id>/projects/<프로젝트 id>/` | 연구지원 화면 |
| 로그·감사 기록 | `<데이터 폴더>/logs/` | 서버(추가만) |
| 백업 | `<데이터 폴더>/_backups/` · `users/<id>/kvsnap/` | 서버가 자동으로 |

**데이터 폴더** 위치는 기본 `userdata/workspace/` 예요. `--data-dir=경로`, 환경변수 `STUDY_DATA_DIR`, `userdata/data-dir.txt` 중 하나로 바꿀 수 있어요.

## 2. 데이터 폴더 구조

```
<데이터 폴더>/
├─ system/                      서버 공통(관리자)
│  ├─ users.json                계정(비밀번호는 PBKDF2 해시만)
│  ├─ sessions.json             로그인 세션(토큰의 해시만 — 백업에서 뺌)
│  ├─ policy.json               보안 정책
│  ├─ secret.key                ★ 저장 암호화 키(AI 키·FlowBoard 토큰) — 잃으면 다시 등록
│  └─ llm_system.json           관리자 공용 AI 연결(Claude CLI 등)
├─ users/<계정 id>/
│  ├─ README.md                 이 폴더 안내(자동)
│  ├─ study/*.kv.json           ⚙ 설정·표시·화면 상태
│  ├─ library/
│  │  ├─ _folders.kv.json       📁 내 학습 폴더(문서 묶음)
│  │  ├─ _reading-progress…     읽은 위치·즐겨찾기
│  │  └─ <문서 id>/             📚 문서 하나의 내 데이터
│  │     ├─ _document           제목(폴더만 봐도 어떤 문서인지)
│  │     ├─ notes · highlights · bookmarks · reading-time · socratic
│  ├─ projects/
│  │  ├─ _INDEX.md              🔬 프로젝트 목록(폴더·묶음별, 자동)
│  │  ├─ _snip · _settings …    표준 문단 보관함·연구지원 설정·이어서 하기 위치
│  │  └─ <프로젝트 id>/
│  │     ├─ README.md           이 프로젝트 안내(이름·목표·연결 폴더·에픽, 자동)
│  │     ├─ project.json        정보(이름·종류·목표·묶음(group)·연결 폴더(source)·에픽(epic))
│  │     ├─ files/              올린 자료 원본 + 추출 텍스트(.txt) + 정보(.json, 원래 파일 이름)
│  │     ├─ docs/<문서 id>/     문서 버전 v0001.json… (저장할 때마다 새 번호, 지우지 않음)
│  │     ├─ out/                내보낸 DOCX·PPTX·HTML·MD·묶음 zip
│  │     ├─ log.jsonl           이력(대화 한 턴·문서 저장·내보내기·자료) — 추가만
│  │     ├─ notes · todo · references (.kv.json)  메모·할 일·참고문헌
│  │     └─ fcache/             연결 폴더 문서의 추출 텍스트 캐시(지워도 다시 만들어짐)
│  ├─ tools/ · ui/              공용 도구(뽀모도로 기록)·화면 상태
│  ├─ llm.json                  내 AI 연결(키는 암호화)
│  ├─ kanban.json               FlowBoard 연결(토큰은 암호화)
│  ├─ masters.json              마스터 폴더 목록
│  ├─ _journal.jsonl            변경 일지(어떤 항목이 언제 어느 기기에서 바뀌었는지 — 값은 없음)
│  └─ kvsnap/                   하루 첫 저장 직전 전체 사본(60일) · 덮기/되돌리기 직전 사본
├─ logs/                        server·error·access·llm·client(5MB×10) / audit·activity(날짜별 10년)
├─ _backups/ws-YYYYMMDD.zip     하루 첫 쓰기 때 users/+system/ 자동 압축(30개)
└─ _trash/                      지운 프로젝트·자료(되살릴 수 있음)
```

### 파일 형식
- **`.kv.json`**: 항목 하나 = 파일 하나. 내용은 `{k: 키, v: 값(문자열), t: 시각, dev: 기기}`이고, 바로 이전 값은 같은 이름의 `.kv.prev` 에 남아요.
  - 앱에서 무언가 바뀌면 **0.2초 안에 그 항목만** 서버로 가요. 거울 사본이나 몇 초 뒤 통째로 올리는 방식은 쓰지 않아요.
  - 다른 기기의 변경은 **15초 안에** 받아요.
- **`.json`**: 원자적 교체로 저장해요. 쓰다가 꺼져도 이전 파일이 남아요.
- **`.jsonl`**: 추가만 하는 줄 단위 기록이에요. 중간에 끊겨도 앞줄은 멀쩡해요.

## 3. 영역별로 관리하기

### 🔬 연구지원 — 프로젝트 = 폴더
- **새 프로젝트**는 세 가지 방법으로 만들어요.
  - 직접 만들기
  - 📁 로컬 폴더 연결: 그 자리의 파일 구조 그대로 써요(읽기만).
  - 📋 FlowBoard 에픽에서 가져오기
- **🗂 마스터 폴더**를 등록하면 하위 폴더 하나하나가 프로젝트가 돼요(예: Claude Projects 폴더). 새로 생긴 하위 폴더는 [동기화]로 추가해요.
- **📁 폴더 정리**(프로젝트 목록 위)로 프로젝트를 묶음별로 정리해요(예: 2026 과제 · 검토 중 · 완료). 마스터 폴더에서 온 프로젝트는 마스터 이름으로 저절로 묶여요.
- 프로젝트 폴더의 `README.md` 와 전체 목록 `projects/_INDEX.md` 는 저장할 때마다 자동으로 새로 써요. 탐색기로 열어 봐도 무엇인지 알 수 있어요.
- **묶음 내려받기**: [🧰 도구 → 📦 프로젝트 묶음 내려받기]로 자료·문서 전 버전·이력·내보낸 파일을 zip 하나로 받아요.
- **지우기**: [연구지원 관리]에서 프로젝트를 휴지통으로 보내면 `_trash/` 로 옮겨져요. 연결된 로컬 폴더의 원본은 건드리지 않아요.

### 📚 자료 학습 — 문서별 폴더 + 내 학습 폴더
- **학습 자료 원본**(HTML 문서)은 프로그램 쪽 `app-html/library/docs/` 에 있어요. 목록과 분류 이름은 `catalog.json` 에 있어요. 추가하는 방법은 도움말의 '학습 자료 만들기·등록'을 보세요.
- **내 데이터**는 문서마다 `users/<id>/library/<문서 id>/` 폴더에 모여요(노트·형광펜·북마크·읽은 시간·소크라테스 문답).
- **📁 내 학습 폴더**(자료 학습 메뉴)에서 문서를 주제별 폴더로 묶어요.
  - 폴더마다 문서별 데이터를 한 표로 보고, **폴더 학습 묶음(MD)**으로 내려받아요.
  - '📖 공부한 자료' 폴더는 노트·형광펜·북마크·읽은 시간 중 하나라도 있는 문서를 자동으로 모아요.


## 4. 백업 · 복원

| 백업 | 언제 | 무엇을 | 보관 | 되돌리는 법 |
|---|---|---|---|---|
| 항목 직전 값 `.kv.prev` | 항목이 바뀔 때마다 | 그 항목 하나 | 1단계 | 파일을 직접 교체(관리자) |
| `kvsnap/YYYYMMDD.json` | 하루 첫 저장 직전 | 내 계정의 모든 항목 | 60일 | [설정 → 계정·보안 → 실시간 저장 → 이 시점으로 되돌리기] |
| `kvsnap/…-browser/before.json` | 서버 값으로 덮기 전, 되돌리기 직전 | 그 순간의 상태 | 60개 | 위와 같음 |
| 문서 버전 `docs/<id>/vNNNN.json` | 문서를 저장할 때마다 | 문서 전체 | 영구 | [문서 → 버전 N] 열고 다시 저장 |
| `_backups/ws-YYYYMMDD.zip` | 하루 첫 쓰기 | users/ + system/(세션 제외) | 30개 | 압축을 풀어 데이터 폴더에 덮기(서버를 끈 상태에서) |
| `_trash/` | 지울 때 | 프로젝트·자료 | 영구 | 폴더를 원래 자리로 옮기기 |

- [지금 백업(zip)] 버튼은 [연구지원 관리] 또는 [작업 이력·저장소]에 있어요.
- **로그·감사 기록**은 백업 zip 에 넣지 않아요. 대신 `logs/` 에 감사·조작 기록을 날짜별로 10년 보관해요.

## 5. 이사 · 다른 PC
1. 서버를 **중지**해요.
2. 데이터 폴더 **전체를 복사**해요(동기화 폴더에 두어도 돼요). DB 덤프는 필요 없어요.
3. 새 PC 에서 `--data-dir` 로 그 경로를 지정하고 시작해요.
4. `system/secret.key` 가 함께 있어야 AI 키·FlowBoard 토큰을 풀 수 있어요. 없으면 연결만 다시 등록하면 돼요.
5. 연결된 **로컬 폴더**(연구 프로젝트)는 원래 경로를 가리켜요. 새 PC 에서 경로가 다르면 [연구지원 관리]에서 다시 연결해요.

## 6. 보안 · 개인정보
- 데이터 폴더는 계정·기록·암호화 키가 있는 **중요 폴더**예요. 공유 드라이브에 둘 때는 접근 권한을 확인하세요.
- 비밀번호는 해시로만 저장해요. AI 키와 FlowBoard 토큰은 `secret.key` 로 암호화해요.
- 감사 기록(조작·보안)은 입력한 글 내용을 남기지 않아요. 칸 이름과 글자 수만, 비밀번호는 '입력함'만 남아요.
- 로컬 폴더 연결과 마스터 폴더는 서버 PC 의 디스크를 읽기 때문에 **관리자만** 할 수 있고, 감사 기록에 남아요.

## 7. 관리 점검표
- **매주**
  - [계정·서버 관리 → 서버·로그]에서 오류·경고를 확인해요.
  - [연구지원 관리]에서 저장소 남은 공간과 최근 백업을 확인해요.
- **매달**
  - `_backups/` zip 하나를 다른 저장소(외장·클라우드)로 복사해요.
  - `_trash/` 에서 필요 없는 것을 정리해요.
- **분기**
  - 계정 목록(잠김·초기 비밀번호)을 점검해요.
  - AI 연결과 FlowBoard 토큰의 만료를 확인해요.
  - 마스터 폴더를 [동기화]해요.

## 8. 문제 해결
| 증상 | 확인 |
|---|---|
| "서버에 연결할 수 없어요" | 서버를 켰는지, 주소의 포트가 맞는지 |
| 다른 PC 에 기록이 안 보여요 | 같은 계정인지, 같은 데이터 폴더를 쓰는 서버인지, [계정·보안 → 실시간 저장] 상태 |
| 저장 실패 표시 | 서버가 꺼졌던 동안의 변경은 브라우저에 대기했다가 서버가 켜지면 자동으로 보내요 |
| 예전 상태로 돌리고 싶어요 | [계정·보안 → 실시간 저장]의 사본 목록에서 되돌리기(지금 상태도 사본으로 남아요) |
| 연결 폴더 파일이 안 보여요 | 폴더가 그 자리에 있는지, [연구 프로젝트 → 폴더 ↻ 새로 읽기], 숨김·`versions`·`node_modules` 같은 폴더는 일부러 빼요 |
