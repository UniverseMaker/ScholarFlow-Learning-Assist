# 🔬 연구지원 — PDF 를 올려 AI 와 읽고, 문서로 만들기

앱 맨 위의 모드 스위치 **[🔬 연구지원] · [📚 자료 학습]** 로 두 구조를 오가요. 한 앱 안에 있고, 설정·관리자·AI 연결은 공통이에요.

## 어디에 저장되나요 (가장 중요)
- 연구지원의 **모든 것**(프로젝트·올린 자료·대화 한 턴 한 턴·문서 버전·내보낸 파일)은 **서버 폴더**에 파일로 저장돼요. 브라우저를 바꿔도, PC 를 바꿔도 그대로예요.
- 기본 폴더: 프로젝트의 `userdata/workspace/`. 바꾸려면 `python serve.py 18162 --data-dir="원하는 폴더"` 또는 `userdata/data-dir.txt` 에 경로 한 줄, 환경변수 `STUDY_DATA_DIR`.
- **옮기기 = 폴더 복사.** DB 가 없어요. 폴더를 복사하거나 동기화 폴더(Drive·OneDrive)에 두고 새 PC 에서 `--data-dir` 로 가리키면 끝.
- 잃어버리지 않게: 쓰기는 임시 파일 → 교체(쓰다 꺼져도 이전 파일 보존) · 이력은 **추가만 하는** 줄 단위 로그(`log.jsonl`) · 문서는 **저장마다 새 번호**(지워지는 버전 없음) · 삭제는 `_trash/` 로 이동 · 하루 첫 쓰기 때 `_backups/ws-날짜.zip`(30개 보관).
- 서버가 꺼져 있을 때 쓴 대화·문서는 이 브라우저에 **대기**했다가 서버가 켜지면 자동으로 보내요(상단 "○ 저장소 꺼짐 · 로컬 대기 N"). 파일 올리기는 서버가 켜져 있어야 해요.
- 서버 켜기: 프로젝트 폴더에서 `python serve.py 18162`. 클라우드플레어 터널로 열어 두면 어느 기기에서나 같은 저장소예요. 파이썬에 `pymupdf`(PDF 추출) · `python-docx` · `python-pptx` 가 있어야 하며, 없으면 [작업 이력 · 저장소] 가 알려 줘요.

## 흐름
1. **프로젝트 만들기** — 이름 · 종류(연구개발계획서 / 논문 / 보고서 / 정책·공고 / 강의 자료) · 목표.
2. **자료 올리기** — 왼쪽 📎 에 PDF·txt·md·docx·pptx 를 끌어다 놓기. 쪽 단위로 텍스트를 뽑아 색인해요(스캔본 PDF 는 텍스트가 없어 OCR 이 필요 — 원본 열기로 볼 수는 있어요). 체크를 끄면 그 자료는 대화 근거에서 빠져요.
3. **💬 대화** — 질문하면 관련 쪽을 골라(BM25) 근거로 넣고 **(파일 p.N)** 으로 인용해요. 빠른 질문: 핵심 요약 · 목표와 필요성 · 추진 체계 · 일정 · 예산 · 기대 효과 · 평가자 관점 약점 · 예상 질문 10개. 답변의 **[📝 문서에 넣기]** 로 바로 문서 절이 돼요.
4. **📝 문서** — 종류(요약본 · 검토 의견서 · 발표 자료 · 브리핑 노트 · 자유)를 고르면 차례가 들어가요.
   - **✨ AI 초안**: 빈 절마다 자료에서 근거를 찾아 채워요(절마다 LLM 1회, 끝나면 자동 저장 "AI 초안").
   - 절마다 **AI ▾**: 자료로 쓰기 · 다시 쓰기 · 더 자세히 · 더 짧게 · 개조식 · 격식체 · 표로 정리 · 근거·쪽 보강 · 예상 질문 3개. **📑 차례 다시 제안**은 자료를 훑어 차례를 바꿔요.
   - 본문은 가벼운 마크다운(`**굵게**`, `- 목록`, `1. 번호`, `| 표 |`, `> 인용`). 👁 미리보기로 확인.
   - **💾 저장** 할 때마다 새 버전. [버전 N] 에서 예전 버전을 열어 다시 저장하면 그 내용이 새 버전으로.
   - **내보내기**: HTML · MD · **DOCX**(제목·절·목록·표) · **PPTX**(표지·목차·절마다 슬라이드, 본문은 발표자 노트). 내보낸 파일도 프로젝트 폴더 `out/` 에 남아요.
5. **📖 자료 보기 = 읽기 작업대** — 왼쪽 뷰어, 오른쪽 [💬 AI · 📌 수집함 · 🗂 주석].
   - **무엇이든 열려요**: PDF(쪽 모양 그대로) · Word·PPT·Excel(이 PC 의 오피스로 쪽 모양 그대로 — 처음 한 번 변환) · 한글(HWP·HWPX, 글) · 표(XLSX·CSV) · 그림 · 소리·영상 · 글·코드·마크다운.
   - **뷰어**: 쪽 목록·목차·책갈피(▤) · ←/→ 쪽 넘기기 · 확대/폭 맞춤/쪽 맞춤 · Ctrl+F 찾기 · 글을 고르면 **형광펜 4색·📝 메모·💬 AI 에게·💡 쉽게·🌐 번역·📌 담기** · 📝 쪽에 메모 핀 · 🔖 책갈피 · 🌙 어둡게 · ⛶ 전체 화면. 영상·소리는 속도·10초·📍 시각 메모·📌 이 구간 담기. 주석은 계정에 바로 저장돼 다른 기기에서도 보여요.
   - **💬 AI** 는 지금 보는 쪽(또는 구간)을 같이 보고, '프로젝트 전체 자료도 참고'를 켜 두면 다른 자료에서도 근거를 찾아요. 답의 (파일 p.N) 을 누르면 그 쪽으로 가요. 빠른 질문: 이 쪽 요약 · 쉽게 설명 · 앞뒤 연결 · 표·수치 정리 · 비판적으로 · 예상 질문.
   - **📌 수집함**: 고른 글·AI 답·주석을 모아(끌어다 놓기도 돼요) 순서를 바꾸고 내 메모를 달아 → **✨ 만들기**(요약 노트·보고서·발표 자료·브리핑·비교표) → 문서로 저장 → DOCX·PPTX·HTML·MD. ⇱ 로 수집함을 옆에 따로 열면 3단으로 써요.
   - 위쪽 **◧ 자료 칸 · 🕘 이력 · ⤢ 크게(Esc) · ⛶** 로 화면을 넓히고, 칸 사이를 끌어 폭을 바꿔요.
   - 폴더 트리에서 쓸모없는 폴더·파일은 🙈 로 숨겨요(파일은 그대로). 프로젝트 목록 [📁 정리] 에서 프로젝트를 숨기거나 지울 수 있고, 마스터 폴더에서 온 것을 지우면 다시 동기화해도 안 생겨요.
6. **작업 이력 · 저장소** — 모든 프로젝트의 타임라인(대화·문서·내보내기·자료), 저장소 상태(폴더·백업·라이브러리), 지금 백업, 다른 PC 로 옮기는 법, 학습 기록 거울.

## 팁
- 발표 자료는 "발표 자료" 종류로 만들면 AI 가 한 장 분량의 개조식으로 써서 PPTX 가 바로 쓸 만해요.
- 검토 의견서는 "평가 항목별 검토" 절에 공고의 평가 기준을 붙여 넣고 **근거·쪽 보강** 을 누르면 계획서의 해당 쪽을 찾아 붙여요.
- 긴 PDF 여러 개를 올렸다면, 질문할 때 체크로 근거 자료를 좁히면 더 정확해요.
