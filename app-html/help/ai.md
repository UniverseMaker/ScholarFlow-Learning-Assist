# AI 연결

앱에는 기본 AI 연결이 없습니다(키를 코드에 두지 않음). **설정 → AI 연결**에서 프로필을 불러와 연결하세요.

## 프로필 파일
```json
{ "type": "llm-lab-profiles",
  "profiles": [ { "service": "사내 LLM", "base_url": "https://…/v1", "model": "모델 이름",
                  "auth": { "api_key": "…" }, "params": { "temperature": 0.6, "max_tokens": 2048, "timeout_ms": 60000 } } ] }
```
`base_url` 과 `model` 만 있으면 됩니다(OpenAI 호환 `/chat/completions`). 여러 개를 등록하고 [연결]로 바꿀 수 있어요. [테스트]로 응답을 확인하세요.

## 연결 정보는 계정마다 따로
- 불러온 프로필(키 포함)은 **지금 로그인한 계정에만** 저장돼요. 같은 브라우저의 다른 계정은 보지도 쓰지도 못해요.
- 관리자의 [데이터 센터 → 모든 사용자] 내보내기에도 **다른 계정의 연결 정보는 절대 들어가지 않아요**(자기 것만, 그것도 '비밀 포함'일 때만 키 포함).
- 예전 버전(v70 이하)에서 브라우저 전체에 하나로 저장돼 있던 프로필은 관리자 계정으로 처음 열 때 그 계정으로 옮겨져요.

## ☁ 내 계정 보관함 — 올리기 · 받아 쓰기 (DB 없이)
다른 브라우저·PC 에서도 같은 연결을 바로 쓰도록, 연결 정보를 **계정 이름 + 암호 문구**로 잠가 둡니다.

**어디에 저장되나** — 설정 화면의 안내 줄에 지금 방식이 보여요.
| 여는 방법 | 보관 위치 | 다른 브라우저에서 받기 |
|---|---|---|
| **PHP 공용 호스팅**(앱 폴더에 `api.php` 함께) | 🌍 호스팅 서버 `_vault/` — 암호문만 | **이 주소로 여는 어느 PC·브라우저든** 같은 계정 이름 + 같은 문구 → [⬇ 받아 쓰기]. 올리는 법 → [배포](#help:deploy) |
| `python serve.py 18162` 로 띄운 주소 | 🖥 **이 PC 폴더** `userdata/llm-vault/<id>.json` — 암호문만 | 같은 주소로 열고 **같은 이름의 계정**으로 로그인 → 같은 암호 문구 → [⬇ 받아 쓰기] |
| **동기화 폴더 지정**(권장 — 다른 컴퓨터) | ☁ Google Drive·OneDrive 같은 **동기화 폴더** | 각 PC 의 serve.py 가 같은 폴더를 보게 하면 끝 — `userdata/vault-dir.txt` 에 폴더 경로 한 줄(또는 `--vault-dir=경로`, 환경변수 `STUDY_VAULT_DIR`) |
| `python serve.py 18162 --lan` (같은 네트워크) | 서버 PC 의 폴더 | 다른 PC 에서 `http://<서버 PC IP>:18162` 로 접속해 똑같이 |
| 정적 호스팅·파일로 열기(서버 API 없음) | 🌐 이 브라우저만 | **🔐 암호화 파일로 저장** → 다른 곳에서 **📂 암호화 파일에서 받아 쓰기** |

| 버튼 | 하는 일 |
|---|---|
| **⬆ 올리기** | 지금 프로필 전부를 암호화해 보관함에(같은 이름+문구로 올린 것은 바뀜). 파일 보관함은 암호 문구가 꼭 있어야 해요 |
| **⬇ 받아 쓰기** | 암호 문구로 보관함을 찾아 이 브라우저에 넣고, 올릴 때 쓰던 연결로 **바로 연결** |
| 🔐 암호화 파일로 저장 | `llm-vault_YYYYMMDD.json` — 파일만으로는 키를 못 읽어요(같은 문구 필요) |
| 📂 암호화 파일에서 받아 쓰기 | 위 파일(또는 평문 `llm-lab-profiles` 파일)을 골라 바로 넣기 |
| 💾 평문 파일로 저장 | 키가 그대로 든 파일 — 꼭 필요할 때만, 쓰고 지우기 |
| 보관함 비우기 | 이 브라우저 사본 + (문구를 넣으면) 파일 보관함의 내 것 |

- **"저장됐다는데 다른 컴퓨터엔 없어요"** — 기본 폴더(`userdata/llm-vault`)는 **그 PC 안**이라 다른 컴퓨터의 serve.py 는 못 봐요. 위 표의 동기화 폴더 지정이나 `--lan`, 암호화 파일 중 하나로 이어 주세요. (v71~v74 는 브라우저 안에만 저장돼서 같은 PC 의 다른 브라우저에서도 안 보였어요.)
- 암호화: **AES-256-GCM**, 키는 암호 문구에서 PBKDF2-SHA256 21만 회. 보관함을 찾는 이름표(id)도 계정 이름+문구로 따로 만들어서, 이름이나 문구를 모르면 **찾을 수도 풀 수도 없어요**. 서버·관리자·다른 계정은 내용을 볼 수 없고, 서버는 평문이 섞인 저장 요청을 거부해요.
- 암호 문구를 잊으면 복구할 수 없어요 — 프로필을 다시 불러와 새 문구로 다시 올리세요.
- 브라우저마다 계정이 따로 만들어지므로, 받는 쪽에서도 **올릴 때와 같은 계정 이름**으로 로그인해야 해요(비밀번호는 브라우저마다 달라도 됨 — 보관함은 암호 문구로 잠겨요).
- 감사 기록엔 "올렸다/받았다"만 남고 키·문구는 남지 않아요.
- 없는 보관함을 1분에 30번 넘게 찾으면 잠깐 막아요(마구 찔러 보기 방지).

## AI 가 쓰이는 곳
연구 프로젝트 대화(근거 인용) · AI 작업 · 논문·보고서·발표자료 작성 보조 · 문헌 정리 · 모의 심사 · 학습 자료 요약·질문·복습 카드 · 💬 물어보기.
연결이 없으면 이 기능들은 "AI 연결이 필요해요"로 멈추고, **자료 읽기 · 문서 편집 · 내보내기**는 그대로 됩니다.

## 안 될 때
- 상단 ● 이 빨강 → 설정의 [테스트] 오류 문구 확인(주소·모델 이름·키)
- 사내망 서버는 브라우저에서 접근 가능한 주소여야 합니다
