# 🖥 서버 · 계정 보안 · AI 연결

## 서버 켜고 끄기
- 프로그램 폴더에서 `python serve.py <포트> --data-dir=<데이터 폴더>`. 끄려면 그 창에서 Ctrl+C.
- 필요한 파이썬 패키지는 `requirements.txt`(없어도 서버는 뜨고, 해당 기능만 멈춰요).

## 로그 — 무슨 일이 있었는지
로그는 `<데이터 폴더>/logs/` 에 쌓여요. [관리자 → 계정 · 서버 관리 → 서버 · 로그]에서 볼 수 있어요.

| 파일 | 내용 |
|---|---|
| console.log | 서버 화면 출력 |
| server.log | 모든 분류의 INFO 이상 |
| error.log | 경고·오류만 |
| access.log | API 요청: 경로·상태·걸린 시간·계정·요청 id |
| activity.log | 조작 감사: 모든 화면·버튼·설정 변경·업로드·내려받기 (날짜별 파일, 10년) |
| audit.log | 보안 감사(날짜별 파일, 10년): 로그인 성공/실패, 잠김, 비밀번호 변경, 계정·권한·정책 변경, AI 연결 변경 |
| llm.log | AI 호출: 누가·어떤 연결·모델·시간·글자 수 (대화 내용은 남기지 않아요) |
| client.log | 브라우저에서 난 오류(자동 보고) |

- 한 줄이 JSON 하나예요. 5MB 마다 새 파일로 넘어가고, 10개까지 보관해요.
- 비밀번호·키·토큰은 자동으로 가려져요.
- 오류 화면에 "요청 id"가 보이면, 그 id 로 error.log 를 찾으면 돼요.

## 계정과 보안
- 서버로 열면(`http://127.0.0.1:18162`) **서버 계정**으로 로그인해요.
  - 비밀번호는 서버에 PBKDF2(60만 회)+솔트 해시로만 저장돼요.
  - 로그인은 HttpOnly 쿠키로 유지돼요. 자바스크립트가 읽을 수 없고, 30일 동안 유지돼요.
- **초기 관리자(admin)의 기본 비밀번호는 이 PC 에서만** 통해요.
  - 클라우드플레어 터널·LAN 으로 쓰려면 먼저 **[설정 → 계정 · 보안]** 에서 비밀번호를 바꾸세요.
- 비밀번호를 5번 틀리면 5분 잠겨요. 또 틀리면 15분, 그다음은 1시간이에요.
- **[설정 → 계정 · 보안]**
  - 비밀번호 바꾸기: 바꾸면 다른 기기의 로그인은 모두 끊겨요.
  - 로그인된 기기 보기·로그아웃시키기
  - 내 보안 기록
- **[관리자 → 계정 · 서버 관리]**
  - 계정 만들기(임시 비밀번호 → 다음 로그인 때 바꾸라고 안내), 역할·플랜, 잠그기·풀기, 비밀번호 초기화, 삭제(데이터 폴더는 보존)
  - 보안 정책: 스스로 가입, 원격 기본 비밀번호, 비밀번호 길이, 로그인 유지 기간, 일반 사용자의 AI 연결 등록·사설망 주소
  - 서버 정보·로그
- 다른 사이트가 몰래 보내는 요청은 서버가 막아요(전용 헤더 + 출처 확인 + SameSite 쿠키). 연구 저장소의 계정도 로그인 세션에서만 정해져요.

## AI 연결 — 계정별로 서버에
- **[설정 → AI 연결]** 에서 [➕ 연결 추가]를 눌러요.
  - 종류: OpenAI 호환 API(vLLM·Ollama·LM Studio·OpenRouter·OpenAI…)
  - 이름 · 주소(base_url) · 모델 · API 키
- **API 키는 서버에 암호화돼 있고 브라우저로 오지 않아요.**
  - AI 호출은 서버가 대신 해요(프록시). 그래서 어느 브라우저·기기에서 로그인해도 같은 연결을 써요.
  - 다른 계정은 내 연결을 볼 수 없어요.
- 예전에 브라우저에 저장했던 연결은 서버로 로그인할 때 **자동으로 내 계정으로 옮겨지고**, 브라우저 사본(키)은 지워져요.
- 관리자는 **공용 연결**을 만들 수 있어요. [모든 계정에 공유]를 켜면 다른 계정도 고를 수 있어요.
- 일반 사용자는 기본적으로 사설망·localhost 주소를 등록할 수 없어요(서버가 대신 요청하므로). 정책에서 바꿀 수 있어요.

### 🤖 Claude CLI 연결
- 관리자가 **[🤖 Claude CLI 연결]**을 누르면, 이 PC 에 로그인된 Claude Code(`claude` 명령)를 AI 로 써요. 모델은 Sonnet·Opus·Haiku 중에서 골라요.
- 서버가 `claude -p` 를 **도구·MCP·설정 파일 없이**, 빈 작업 폴더에서 실행해 답만 받아요. 파일을 읽거나 명령을 실행하지 않아요.
- PC 주인의 Claude 구독을 써요. 그래서 기본은 관리자만 쓸 수 있고, [모든 계정에 공유]를 켜야 다른 계정도 써요.
- 한 번에 2개까지 처리해요. 온도·최대 토큰은 CLI 가 정해요.

## 하던 것 그대로 이어서 (계정에 진행 저장)
- 설정·화면 상태는 바뀔 때마다 자동으로 **내 계정(서버)** 에 저장돼요.
  - 다른 브라우저·PC 에서 로그인하면 하던 그대로 이어져요.
  - 연구지원은 마지막 프로젝트·탭·문서, 보내지 않은 질문, **저장 안 한 문서 수정**까지 다시 열려요.
  - 자료 학습은 마지막으로 읽던 문서와 위치가 다시 열려요.
- 로그인하면 **🔬 연구지원**부터 시작해요.
- 다른 기기의 진행이 더 새로우면 자동으로 받아요. 이 브라우저에도 안 올린 변경이 있으면 어느 쪽으로 이어갈지 물어봐요.
- 덮어쓰기 전 상태는 항상 보관돼요. **[설정 → 계정 · 보안 → 진행 저장]** 에서 원하는 시점으로 되돌릴 수 있어요(최근 60개).

## 조작 감사 기록
- 연구지원·자료 학습에서 하는 모든 조작이 `logs/activity.log` 에 남아요.
  - 남는 것: 화면 열기, 모드 전환, 버튼·메뉴 누름, 선택·체크 변경, 입력칸 변경, 파일 고름, 단축키, 학습 자료 문서 열기, 서버 저장소 쓰기·문서/파일 열람
  - 입력한 **글 내용은 남기지 않아요**. 칸 이름과 글자 수만 남고, 비밀번호는 '입력함'만 남아요.
- 감사 로그(audit·activity)는 **날짜별 파일로 10년** 보관해요.
- 관리자는 **[계정 · 서버 관리 → 서버 · 로그 → 조작 감사]** 에서 계정·날짜로 걸러 볼 수 있어요.

## 옮기기
- 데이터 폴더(기본 `userdata/workspace`)를 **통째로 복사**하면 이사가 끝나요. 다음이 모두 함께 옮겨져요.
  - 계정(`system/users.json`)과 보안 정책
  - AI 연결 + 암호화 키(`system/secret.key`)
  - 연구 프로젝트와 로그
- `system/secret.key` 가 없으면 저장된 API 키를 풀 수 없어요. 그때는 연결을 다시 등록하면 돼요.
- 그래서 데이터 폴더 자체를 소중히(남과 공유하지 않게) 다뤄 주세요.
